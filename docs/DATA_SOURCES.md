# Data sources

Everything FlightGlobe shows comes from one of two places: **bundled sample
data** (always available, works offline) or **free public APIs** (optional,
best-effort, no keys). The app never requires the network.

## Bundled data (`data/`)

Generated by `scripts/generate-data.py` (seeded, reproducible).

| File | Contents | Provenance |
| --- | --- | --- |
| `airports.json` | 40 major airports: IATA code, name, city, lat/lon | Public knowledge (airport locations) |
| `flights.json` | 49 sample flights: id, from/to, dep/arr (UTC), airline, aircraft | Invented schedules for 18 Nov 2026 — realistic routes and timings, not a real timetable |
| `earthquakes.json` | 30 sample quakes: lat/lon, magnitude, place, depth, time | Locations near real seismic zones (Japan, Indonesia, Chile, Alaska…); magnitudes and times invented |
| `satellites.json` | 12 satellites: inclination, period, phase, altitude | Real satellites (ISS, Starlink, NOAA-20, Sentinel-2A, Landsat 9, Hubble, Tiangong, OneWeb, GPS III, GOES-16) with approximate public orbital parameters |
| `land.json` | 14 simplified coastline polygons | Hand-drawn recognisable outlines, not survey-grade |

Satellite positions use a simple circular-orbit model, not SGP4/TLE
propagation — good enough to show orbit rings and moving dots, and labelled
as sample data in the app.

## Live data (optional)

| Source | Endpoint | Key? |
| --- | --- | --- |
| OpenSky Network | `https://opensky-network.org/api/states/all` | No |
| USGS Earthquake Hazards | `https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/2.5_day.geojson` | No |

Both are fetched with a 6-second timeout from `js/live.js`. On any failure
(network down, non-200, empty result) the app keeps the bundled data and the
header badge stays on "Bundled sample data". When live data arrives, the badge
switches to "Live: OpenSky flights + USGS quakes · fallback bundled".

## Regenerating the bundled data

```bash
python3 scripts/generate-data.py
npm run validate-data
```
